# Visual assets

The icon and glass interface frames were authored for UTUVO convert and are
included under the repository MIT license. Blender-rendered frames are shipped
as PNGs so building the app does not require Blender. The icon was produced
with an image-generation tool and exported with macOS system tools.

Local render-path and creation metadata have been removed from the published
PNGs; compressed pixel data is unchanged. UI code composes the frames at runtime.
UTUVO names and logos do not grant trademark or endorsement rights.
