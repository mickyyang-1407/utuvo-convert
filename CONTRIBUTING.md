# Contributing

Open an issue with a reproducible scenario, expected/actual behavior, macOS
version and relevant diagnostics. Use synthetic or redistributable test audio;
do not post private recordings, credentials or signing material.

Keep changes focused and run `sh scripts/test.sh` for engine changes. For UI
changes, also build the app and verify the affected interaction. Distinguish
command-line tests from actual GUI or listening checks.

Contributions are accepted under the project's MIT license. Preserve the
licenses and attribution of third-party material.
