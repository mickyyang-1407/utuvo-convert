01 / INPUT

拖入一個檔案，或整個資料夾。

先分析來源，再決定輸出格式與聲道排列；不靠聲道數猜測不明的排列。

02 / CONVERT

替這次工作，選對輸出。

保留原排列、Downmix，或使用實驗性 PCM Upmix。MP3 支援單／雙聲道。

03 / CHECK

完成後，保留可查看的結果。

每個輸出附 JSON 轉換與 QC 報告。已有同名輸出時拒絕覆寫，讓你換個資料夾重試。

開始前，知道這幾件事。

Upmix 會產生 Dolby Atmos 嗎？

這是估測的多聲道 PCM，不會產生 Atmos objects、ADM 輸出或 Dolby Digital Plus JOC。實體環繞／高度喇叭的聽感與相容性仍需另外驗收。

QC PASS 代表什麼？

包括格式、時長、取樣率、聲道數與有限樣本檢查，不保證播放峰值低於 0 dBFS。MP3 有損重建可能產生超過滿刻度的峰值，App 會顯示警告；不會暗中正規化音量。

檔案與系統有哪些限制？

一般來源解碼 PCM 有 512 MiB 安全上限。來源描述標籤不會複製，降位深不加 dither。目前建置在 Apple Silicon／macOS 27 驗證；其他 Mac／系統版本尚待測試。閱讀完整限制。
